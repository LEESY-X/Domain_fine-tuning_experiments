# File Manifest

This manifest describes the intended role of each top-level file or directory in the submission package.

| Path | Role |
|---|---|
| `README.md` | Main paper-facing reproducibility guide. |
| `submission_checklist.md` | Practical checklist for paper supplement or GitHub upload. |
| `file_manifest.md` | Description of the submitted file surface. |
| `.gitignore` | Ignore rules for caches, checkpoints, logs, and local outputs. |
| `requirements.txt` | Minimal Python dependency list. |
| `requirements-followup.txt` | Pinned top-level package versions recorded for the 2026-08-07 follow-up; not a complete transitive or OS lock. |
| `config/experiment_config.json` | Reproducible experiment settings, seeds, methods, and hyperparameters. |
| `config/collapse_followup.json` | Four-condition collapse follow-up and ablation specification. |
| `src/suite.py` | Main experiment implementation. |
| `src/result_analysis.py` | Prediction-collapse diagnostics, strict seed aggregation, and paired statistics. |
| `src/__init__.py` | Python package marker. |
| `tools/` | Validation, notebook creation, progress checking, and reporting utilities. |
| `notebooks/` | Clean, output-free local workflow notebooks generated by `tools/create_notebooks.py`. |
| `colab_a100_full_550_runs.ipynb` | Full Colab execution notebook. |
| `colab_a100_low_drive_550_runs.ipynb` | Low-storage Colab execution notebook. |
| `final_tables/summary_by_task_model_method.csv` | Main aggregate result table. |
| `final_tables/winners_by_metric.csv` | Method winners by performance, efficiency, and stability. |
| `results/environment.json` | Recorded run environment. |
| `results/followup/` | Public compact aggregates/environment records plus ignored local per-run follow-up artifacts. |
| `results/followup/provenance.json` | Exact model commits and pilot/full dataset split fingerprints for the follow-up. |
| `results_summary/` | Human-readable summaries for experiment results and interpretation. |
| `results_summary/REPRODUCIBILITY_RECORD.md` | Single-file audit record covering protocol, data, environments, hashes, commands, checks, and known reproducibility gaps. |
| `results_summary/PAPER_CONTENT_CANDIDATES.md` | Paper-section, table, figure, additional-experiment, limitation, ethics, and claim checklist. |
| `results_summary/paper_followup/` | Paper-ready Markdown, CSV, LaTeX, canonical report artifact, and portable HTML report. |
| `docs/experiment_overview.md` | Experiment design overview. |
| `github_assets/README.md` | Optional GitHub-facing asset notes. |
| `release/ieie-spc-v1.0.0/` | Version scope, run coverage, validation boundary, manifest, and SHA-256 checksums. |

The package is designed to be small and reviewable. Raw checkpoints and dataset/model caches remain excluded. The original 550-run per-run artifacts are unavailable. The bounded 100-run follow-up publishes compact metric-level rows; per-example predictions and other run files are retained only in the local audit workspace.
